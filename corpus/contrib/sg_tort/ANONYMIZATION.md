# Anonymization Rules

- Replace real names with fictional names.
- Replace exact organisations with generic Singapore settings unless permission is attached.
- Remove matriculation numbers, phone numbers, addresses, emails, and identifiers.
- Do not include screenshots, page numbers, or wording that can identify a real exam paper.
- If a fact pattern is inspired by a public event, change enough facts that it is not a disguised copy.
- Use source URLs only for legal rule review; do not copy source wording into the record.
