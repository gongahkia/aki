# Contributor Certification

By submitting SG Tort hypo text, the contributor certifies:

1. The submitted fact pattern, issue list, rubric, and answer text are original or the contributor has written permission to license them to this project.
2. The submission does not copy real exam paper text, tutorial handouts, paid bar-prep material, private notes, or account-gated content.
3. The submission contains no real personal data or confidential facts.
4. Any third-party source used for rule checking is listed as metadata only, not copied as hypo text.
5. The contributor has the right to submit the text under the project contribution terms.

Each record must set:

```json
"source_exam_context": {
  "source_type": "repo_authored_submission",
  "authorship_basis": "original_or_permissioned",
  "contributor_role": "student|lecturer|project",
  "certification": {
    "originality_certified": true,
    "permission_certified": true,
    "no_real_exam_text": true,
    "no_personal_data": true
  }
}
```
