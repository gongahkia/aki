# Hosted Demo Deployment

Status: deploy-ready; public URL still required for issue #13.

## Target

Host the FastAPI app as the public demo surface:

- `GET /demo` or `/demo/generate`: browser generation form.
- `GET /demo/pipeline`: pipeline trace.
- `POST /workflow/generate`: SG Tort generation API.
- `GET /health`: platform health check.

## Chosen Path

Use a Dockerized FastAPI service on Render first. This matches the smallest
repo-native path: Render supports Docker web services from a root `Dockerfile`,
and the service uses the Dockerfile `CMD` unless `dockerCommand` overrides it.
The Dockerfile preinstalls the CPU-only PyTorch wheel before installing repo
dependencies to avoid CUDA wheel downloads on CPU web-service instances.

Fallbacks:

- Railway: root `Dockerfile` is auto-detected; generate a public domain after deploy.
- Fly.io: deploy the same Dockerfile with a `fly.toml` generated by `fly launch`.

## Required Secrets

Set server-side provider credentials in the host dashboard. Visitors must not
provide API keys.

| Secret | Required | Notes |
|---|---:|---|
| `OPENAI_API_KEY` | yes for Render default | The browser page can select `openai`. |
| `ANTHROPIC_API_KEY` | optional | Enables Anthropic provider. |
| `GOOGLE_API_KEY` | optional | Enables Gemini provider. |
| `LOCAL_LLM_HOST` | optional | Only if a reachable local/OpenAI-compatible endpoint exists. |

## Render Steps

1. Connect the GitHub repo to Render.
2. Create from `render.yaml` or create a Web Service manually.
3. Use Docker runtime, root `Dockerfile`, and `/health` as the health check.
4. Set `OPENAI_API_KEY` in Render environment variables.
5. Keep `LLM_PROVIDER=openai` and `LLM_MODEL=gpt-4o-mini`, or set an
   equivalent server-side provider/model pair.
6. Deploy and wait for `/health` to return JSON.
7. Open `/demo` and generate an SG Tort hypothetical with model answer.
8. Replace `https://jikai-demo.onrender.com` in `render.yaml` and README with
   the actual public URL.

## Local Container Smoke

```console
$ docker build -t jikai-demo .
$ docker run --rm -p 8000:8000 \
  -e PORT=8000 \
  -e ENVIRONMENT=production \
  -e API_DEBUG=false \
  -e API_RATE_LIMIT=30 \
  -e OPENAI_API_KEY="$OPENAI_API_KEY" \
  jikai-demo
$ curl -sf http://127.0.0.1:8000/health | python3 -m json.tool
```

## Abuse Controls

- In-process IP bucket limiter: `API_RATE_LIMIT` per
  `API_RATE_LIMITER_BUCKET_TTL_SECONDS`.
- Request timeout: `LLM_TIMEOUT=90` and browser abort at 95 seconds.
- Provider circuit breaker: existing LLM service trips after repeated provider
  failures.
- Error mapping: `/workflow/generate` returns stable JSON messages for provider
  timeouts, rate limits, auth failures, and invalid topics.

Edge or platform-level rate limiting is still recommended for a launch window.

## Cost And Privacy Copy

server-side provider and tells users not to enter personal, privileged, or
exam-confidential material.
