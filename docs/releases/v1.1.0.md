# Jikai v1.1.0

Status: published on GitHub as `v1.1.0`  
Release URL: https://github.com/gongahkia/jikai/releases/tag/v1.1.0  
Target commit: `a8645f23bc9e3a22fc8597b6012163cd8ac19c1c`

This is the historical release marker for issue #1, covering the first ChromaDB-backed vector retrieval implementation.

## Scope

- Added `src/services/vector_service.py` for local ChromaDB storage and `sentence-transformers` embeddings.
- Added corpus indexing into the vector collection.
- Routed corpus queries through semantic search before falling back to topic overlap search.
- Kept vector failures non-fatal so local Ollama-backed workflows can continue with fallback retrieval.
